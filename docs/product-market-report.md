# PrioriTodo 事業性・Notion差別化レポート

## 1. 結論

PrioriTodo は、現時点では「完成度の高い汎用ツール」ではなく「大学生の課題管理に強く刺さる可能性がある専用ツール」です。Notion と同じ土俵で汎用性・自由度・デザイン完成度を競うと不利ですが、大学生が毎週発生する課題・授業・提出日を管理する用途に絞れば、500人規模のユーザー獲得や小規模広告収益化を狙えるポテンシャルはあります。

ただし、企業譲渡を見据えるなら、現状のまま機能追加を続けるのではなく、以下の3点を優先して「信頼できるプロダクト」に寄せる必要があります。

1. タスクがいつ、なぜ表示されるのかをユーザーが確認できる透明性。
2. 授業・祝日・繰り返しの大学差分を吸収できる設定設計。
3. Notion 的な情報階層、余白、状態表示に基づく UI 再設計。

## 2. 「売れる」の定義別評価

### 2.1 500人ユーザー獲得

可能性はあります。特に、以下の条件を満たせば達成現実度は高いです。

- ターゲットを「課題提出が多い大学生」に絞る。
- 時間割登録から課題繰り返し生成までを最短で体験できるオンボーディングを用意する。
- 友人紹介・学科内共有・SNS投稿で拡散できる仕組みを用意する。

一方で、現在の UI は「機能はあるが信頼しきれない」状態になりやすく、初期ユーザーが継続するかは改善が必要です。

### 2.2 月1万円広告収入

広告収入だけで月1万円を安定して得るには、日常的に開かれる頻度が重要です。課題管理アプリは、試験前や提出日前に利用頻度が上がる一方、毎日必ず開くとは限りません。

そのため、広告収益を狙うなら以下が必要です。

- 今日やることが毎日見たくなるホーム画面。
- 授業課題の自動生成により、放置しても価値が残る仕組み。
- 広告を邪魔に感じさせない表示位置。

月1万円は、500人規模のユーザーだけでは難しい可能性があります。広告単価や利用頻度次第ですが、安定化には数千 MAU 以上を目標にする方が現実的です。

### 2.3 企業譲渡ポテンシャル

現時点では未成熟ですが、以下の形に磨けばポテンシャルはあります。

- 大学生向け課題管理・時間割管理の特化アプリ。
- 大学/学部/授業単位のテンプレートデータを持つプラットフォーム。
- 学習支援、キャリア支援、大学生マーケティング企業にとって価値があるユーザーベースを持つサービス。

譲渡価値は、単なる ToDo アプリではなく「大学生の行動データ・課題管理導線・授業テンプレート」を持てるかで決まります。

## 3. Notion と比較した差別化

### 3.1 Notion に負ける点

- UI の完成度、情報階層、余白、タイポグラフィ。
- 自由度の高さ。
- データベース、テンプレート、ドキュメント管理の汎用性。
- ブランド信頼性。

Notion は「自由に作れる」ことが価値です。PrioriTodo がここを追いかけると、ほぼ確実に勝てません。

### 3.2 Notion に勝てる可能性がある点

PrioriTodo が勝てるのは、「自由度」ではなく「考えなくて済むこと」です。

- 時間割から課題を自動生成できる。
- 初回授業日と初回締切日から、毎回の提出日を展開できる。
- 締切・開始日・優先度をもとに、今日やるべきことを自動で並べられる。
- 祝日・オンデマンド・隔週提出など、大学生活特有の細かい事情を扱える。

Notion でも手動でデータベースを組めば似たことはできますが、大学生にとっては設定が重いです。PrioriTodo は「初期設定すれば勝手に出る」ことを価値にすべきです。

## 4. 勝ち筋

### 4.1 コアメッセージ

「授業を入れるだけで、次にやる課題が自動でわかる」

この一文に収束させるべきです。

### 4.2 最重要機能

1. 時間割登録。
2. 科目ごとの課題テンプレート。
3. 繰り返し提出日のプレビュー。
4. 今日やるべきことの自動抽出。
5. 表示理由の明示。

### 4.3 Notion 風にするための UI 方針

Notion を真似るべきなのは「白い画面」ではなく、以下の設計思想です。

- 情報の階層が明確。
- 1つの画面で見える意味が整理されている。
- 状態が短いラベルで表現される。
- 装飾よりも余白と文字で整理されている。

PrioriTodo に置き換えるなら、タスク行には以下のような状態ラベルが必要です。

- 表示開始: 4/25
- 次回提出: 5/7 23:59
- 毎週火曜 / 全14回
- 祝日スキップあり
- 優先理由: 締切まで2日

## 5. 現在の弱点

1. ユーザーが「本当に合っているか」を確認しづらい。
2. 授業タスクの内部ロジックが複雑だが、UI 上では十分説明されていない。
3. 祝日・オンデマンド・隔週などの大学差分が設定として整理しきれていない。
4. カード、赤色、影、丸角が多く、意味ではなく装飾で見えてしまう箇所がある。
5. Notion のような落ち着いた完成度より、機能を詰め込んだ印象が先に立つ。

## 6. 優先ロードマップ

### Phase 1: 信頼性の回復

- タスク表示開始日の可視化。
- 繰り返し課題の次回プレビュー。
- 祝日スキップ設定の明確化。
- 保存後に何が生成されたかの確認表示。

### Phase 2: UI の再設計

- 色数を削減。
- 赤色は警告と削除のみに限定。
- カード階層を減らす。
- フォームを「基本」「授業ルール」「表示ルール」に分ける。

### Phase 3: 成長導線

- 時間割テンプレート共有。
- 学科/授業単位の課題テンプレート共有。
- 友人招待・SNS投稿導線。
- 大学別祝日授業プリセット。

## 7. 最終判断

PrioriTodo は、Notion の代替ではなく「Notion で組むのが面倒な大学生向け課題管理を、最初から使える形にしたアプリ」として差別化すべきです。

500人ユーザー獲得の可能性はあります。月1万円広告収入は、利用頻度とユーザー数を伸ばす施策が必要です。企業譲渡レベルにするには、大学生特化のテンプレート・共有・行動データを資産化する必要があります。
